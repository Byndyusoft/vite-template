# Оптимизация производительности

## Базовый принцип

Сначала упрощай структуру состояния и зависимостей, затем добавляй мемоизацию. Мемоизация нужна только там, где она реально уменьшает количество дорогих рендеров или вычислений.

## State colocation

Храни состояние как можно ближе к месту использования. Это предотвращает ререндеры несвязанных частей дерева.

```tsx
function Page(): ReactElement {
    return (
        <>
            <SearchForm />
            <HeavyContent />
        </>
    );
}
```

Если состояние поиска нужно только форме, оно не должно жить в `Page`.

## useCallback

Используй `useCallback`, когда функция передаётся как проп в дочерний компонент, обёрнутый в `memo`, или попадает в массив зависимостей другого хука.

Не используй `useCallback`, если функция применяется только внутри того же компонента и не участвует в зависимостях.

## useMemo

Используй `useMemo` для:

1. ссылочных значений в зависимостях (`object`, `array`, `Map`, `Set`);
2. тяжёлых вычислений, которые измеримо затратны;
3. стабилизации значения, передаваемого в memoized child или context provider.

Не используй `useMemo` для тривиальных вычислений.

## Исправление ссылочного равенства

```tsx
// Плохо: options создаётся заново на каждый рендер.
const options = { page, pageSize };

useEffect(() => {
    load(options);
}, [options]);

// Хорошо: зависимость построена на примитивах.
useEffect(() => {
    load({ page, pageSize });
}, [page, pageSize]);
```

## memo

Используй `memo`, когда компонент часто получает одинаковые пропсы и его рендер заметно дорогой.

Не используй `memo`, если:

- можно изолировать состояние в отдельный компонент;
- дочерний компонент зависит от состояния родителя;
- в пропсах постоянно создаются новые объекты или функции;
- в пропсах передаются `children`, которые пересоздаются при каждом рендере.

## Оптимизация через children

Оборачивай тяжёлый контент как `children`, чтобы ререндер обёртки не каскадировался на уже созданное поддерево.

```tsx
function ColorPicker({ children }: { children: ReactNode }): ReactElement {
    const [color, setColor] = useState('red');

    return (
        <div style={{ color }}>
            <input value={color} onChange={event => setColor(event.target.value)} />
            {children}
        </div>
    );
}
```
