# Стилизация

## Базовый подход

- Глобальные стили держи в `src/index.css`.
- Стили конкретного компонента держи рядом с компонентом.
- Для новых компонентных стилей предпочитай CSS Modules (`*.module.css`). Если продуктовый проект подключил Sass, можно использовать `*.module.scss`.
- Inline-стили используй только для динамических значений, которые нельзя выразить классами.

## Источники стилей

В шаблоне нет готовой дизайн-системы. Если продуктовый проект добавляет токены, палитру, миксины или CSS-переменные, зафиксируй их путь здесь и в `ARCHITECTURE.md`.

Рекомендуемый вариант:

| Файл                         | Назначение                        |
| ---------------------------- | --------------------------------- |
| `src/styles/tokens.css`      | CSS-переменные и дизайн-токены    |
| `src/styles/breakpoints.css` | Breakpoints, если они нужны в CSS |
| `src/styles/index.css`       | Импорт общих стилевых примитивов  |

## Правила

- Цвета, отступы и размеры лучше выносить в токены после появления повторного использования.
- Не дублируй одно и то же значение во многих компонентах.
- Псевдоклассы (`:hover`, `:active`, `:focus-visible`) описывай явно.
- Не скрывай focus-outline без равноценной замены.
- Для CSS, влияющего на доступность, проверяй клавиатурную навигацию.

## Адаптивная вёрстка

Проект использует mobile-first подход: базовые стили для мобильных, затем расширение через media queries.

Рекомендуемые контрольные ширины:

| Экран          | Ширина |
| -------------- | ------ |
| Мобильный      | 360px  |
| Планшет        | 640px  |
| ПК минимальный | 1200px |
| ПК широкий     | 1440px |

Если продуктовый проект имеет другие требования, обнови этот skill и README.

## Поддерживаемые браузеры

По умолчанию ориентируйся на актуальные Chrome, Firefox и Safari. Для CSS-свойств с неоднозначной поддержкой проверяй совместимость и добавляй fallback.
